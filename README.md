# INFORTECH — Proyecto Fénix

Landing page para experiencia de networking con QR.

Construida con HTML/CSS/JS puro — sin dependencias, carga instantánea en mobile.

## Stack
- HTML5 semántico + CSS3 (variables, grid, glassmorphism)
- Canvas API para red de partículas animada
- IntersectionObserver para animaciones de scroll
- Mobile-first, optimizada para tráfico QR

## Secciones
1. Hero — partículas IA + CTAs
2. Beneficios rápidos
3. 5 servicios (AI & Automation como featured)
4. Metodología EVOLVE™
5. Diagnóstico Ejecutivo 360°
6. ¿Por qué Infortech?
7. CTA final + WhatsApp
